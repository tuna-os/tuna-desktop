# Greeter login (greetd-greeter)

RWD machines get a graphical login screen: pick a user, answer
whatever auth prompts appear, choose any installed session, and land
in a running session. The login daemon is adopted (greetd 0.10.3),
never rebuilt; the greeter UI is a GTK4/libadwaita client driven by a
fully headless-tested prompt model.

Why it matters: replaces starting RWD from a text console or relying
on another desktop's login manager, without re-auditing password
handling. Later milestone — 1.0 ships without it.

Deviations from the plan: implementation ran directly in the main
context rather than through workflow implement/test subagents;
evidence is equivalent (97-test workspace suite green plus
independent verify passes per task). UI construction itself is
untestable headless, so view-content decisions carry the coverage.
