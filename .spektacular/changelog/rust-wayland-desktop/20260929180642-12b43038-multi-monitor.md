Roost handles multiple displays now: every connected output gets
its own panel and correctly cropped wallpaper, the dock follows the
primary output, and unplugging a display keeps every window on a
live output with no session restart.

> Derived from project rust-wayland-desktop (plan), spec/plan 20260929180642-12b43038-multi-monitor. See the project-level record for the full feature.

## What changed in this repo

- **Output inventory** (`crates/compositor/src/lib.rs`): one
  entry per output with protocol handle, registry global id,
  size, tiled position, and primary flag; add/remove/upsert,
  primary failover, per-output size/position lookup, and
  primary-first wire records. Removal un-advertises the output's
  global so Wayland clients see the hotplug.
- **Per-output arrange** (`crates/compositor/src/layer.rs`):
  layer surfaces record their bound output at creation and
  arrange/position against it, falling back to primary when
  unbound.
- **Per-size wallpaper cache**
  (`crates/compositor/src/wallpaper.rs`): cover-crops cached per
  output size in bounded slots instead of a single slot.
- **Inventory publish** (`crates/compositor/src/control.rs`,
  `crates/compositor/src/runtime.rs`): new `Message::Outputs`
  broadcast on change and to newcomers (never empty); the tick
  refreshes it from the compositor's tracking.
- **Wire protocol** (`crates/shell-control-schema`): `OutputInfo`
  record plus `Outputs` message, protocol 0.7.
- **Shell intake and surfaces** (`crates/shell-host`): the
  control client stores the inventory; the shell binds
  `wl_output` globals, names them via `xdg_output`, keeps one
  panel per bound output, anchors the dock to primary, and
  reconciles every tick.
- **Hotplug migration** (`crates/compositor/src/windows.rs`):
  floating windows shift into the survivor slice on removal;
  derived layouts re-resolve against the new primary after
  failover.
- **Tests**: 8 inventory, 12 paint/wire/arrange, and 7 migration
  tests, including an end-to-end bound-panel arrange and a
  primary-removal maximized regression; full workspace suite
  green (464 passed).

## Why

A second monitor is table stakes for a modern desktop: without
this, Roost strands windows and shell surfaces on configurations
it cannot describe. The inventory gives every later display
feature — layout configuration UI, per-output scaling work, a
presenting multi-output backend — one source of truth to build
on, owned by the compositor as the spec requires.
