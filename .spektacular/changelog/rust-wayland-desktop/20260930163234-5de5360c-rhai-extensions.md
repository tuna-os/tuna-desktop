# Sandboxed Rhai extensions for the shell

> Derived from project rust-wayland-desktop (spec/plan 20260930163234-5de5360c-rhai-extensions). See the project-level record for the full feature.

Extension scripts (`.rhai` files in the XDG extensions directory)
now contribute bar cells, dock badges, and notes. The engine is
hardened (no `import` from disk, captured print, operation budget,
allowlist API only); scripts run on the slow status tick and
painters read cached outputs, so a bad script disables with a note
instead of harming the session.

## What changed in this repo

- `Cargo.toml`, `crates/shell-host/Cargo.toml`: new `rhai` 1.26
  dependency (offline-resolvable).
- `crates/shell-host/src/extensions.rs` (new): host, API, budgets,
  reload, plus host and battery tests.
- `crates/shell-host/src/panel.rs`: extension host wiring, script
  strip cells with queued press actions, dock badge cells,
  notice-to-banner surfacing, extended paint keys, integration
  tests.
- `crates/shell-host/src/lib.rs`: module registration.
- `crates/shell-host/sample-extensions/hello_cell.rhai`,
  `docs/extensions.md`: sample and user docs.

## Why

The shell had no extension story; every addition required a
rebuild. Scripts now cover cells, badges, and reactions inside a
sandbox the hostile battery proves.
