# Login screen for RWD machines

> Derived from project rust-wayland-desktop, spec/plan 20260928093027-31646037-greetd-greeter. See the project-level record for the full feature.

You can now sign in graphically: a login window lists users and
installed sessions (RWD first), asks for whatever credentials the
system needs, and starts your chosen session. Wrong passwords get a
single generic notice — never a shell — and a crashed session returns
you to the login screen instead of a black display.

What changed in this repo: new `rwd-greeter` crate (prompt model,
greetd conversation client, session-file enumerator, GTK login UI,
scripted fake-daemon contract tests, headless end-to-end
walkthrough), plus a manual VM acceptance procedure for cold boot and
real credentials.

Why: graphical login is the front door of a modern desktop; building
it on the adopted login daemon keeps password handling audited while
the UI stays native RWD.
