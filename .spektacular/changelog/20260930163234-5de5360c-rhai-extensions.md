# Rhai extensions — project record

## What was built

The Roost shell runs sandboxed Rhai extension scripts: bar cells,
dock badges, and user-visible notes from a single plain-text
directory, with per-call operation budgets, hot reload by mtime
polling, and clean disable-with-note on any failure. Twelve new
tests cover the host, a five-script hostile battery, strip/dock
paint integration, press queuing, and reload.

## Why it matters

Extensions are the GNOME customisation story; without them every
bar cell or badge requires rebuilding the shell. Authors get a safe
script directory with docs and a sample; users get customization
that cannot take the session down.

## Deviations from the plan

Press dispatch moved from synchronous handling to slow-tick
draining when the off-path audit found script code on the event
path. Dock badges paint as end-of-row cells (no per-app mapping in
v1). No compositor changes; no new dependencies beyond rhai itself.
