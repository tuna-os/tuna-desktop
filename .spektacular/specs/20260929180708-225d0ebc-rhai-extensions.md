# Feature: 20260929180708-225d0ebc-rhai-extensions

## Overview

Roost gains a sandboxed extension system built on Rhai: small
scripts can add bar cells, dock badges, and indicator reactions
without rebuilding the shell. Extension authors get the
GNOME-extensions equivalent; users get one safe directory of
scripts instead of opaque binaries.

## Requirements

- [ ] **Bar cells from scripts**
  An extension script can contribute a bar cell with text or icon
  and a press action.
- [ ] **Sandboxed execution**
  Scripts run without filesystem, network, or process access
  except through the shell-provided API.
- [ ] **Crash-safe extensions**
  A failing or hanging script is disabled with a visible note and
  never takes the shell down.
- [ ] **Hot reload**
  Adding, changing, or removing a script updates the shell without
  a session restart.

## Constraints

- The scripting engine runs inside the shell process but outside
  its paint and event paths: no script code on the frame path.
- The exposed API is allowlist-only; anything not explicitly
  exposed is inaccessible.
- Extension scripts are plain text in one user directory, never
  binaries.

## Acceptance Criteria

- [ ] **Sample cell ships**
  A sample extension adding a bar cell ships with docs and works
  on a clean session.
- [ ] **Malicious script contained**
  A script attempting filesystem, network, or spawn access is
  denied and disabled; the shell stays up.
- [ ] **Bad script disables cleanly**
  A script with a syntax error or infinite loop is disabled with
  a visible note within one tick.
- [ ] **Reload applies**
  Editing an installed script updates its cell without restart.

## Technical Approach

Decided direction the planner may adapt: Rhai engine with a
hand-built API module (bar cells, bus queries, notices), per-call
timeouts and error capture, file watching for hot reload.

## Success Metrics

- Sample extension cell renders and reacts in a behavioural test.
- Hostile script battery (fs/net/spawn/loop) stays contained in
  test.

## Non-Goals

- Running real GNOME (GJS/Mutter) extensions.
- A graphical extension store or one-click installs.
- Script access to window content or input injection.
