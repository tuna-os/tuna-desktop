# Tuna Desktop 1.0.0-beta.1

First prerelease of Tuna Desktop (formerly Roost): a Wayland desktop built on Smithay with a GTK 4 shell, aiming to match GNOME 51 as shipped in TunaOS Marlin. Package versions: Debian `1.0.0~beta.1`, Arch `1.0.0beta.1`; `--version` reports `1.0.0-beta.1`. This is a beta. It does not claim the [v1 gates](../v1.md) or the [roadmap release gates](../roadmap.md#global-decision-gates).

## Changes

Covers `main` from the first commit (2026-09-28) to the tagged commit.

### Overview, search and app grid
- GNOME 51 overview: live window previews, workspace thumbnails strip, dash, drag between workspaces and insertion between thumbnails (#125, #150, #152, #233, #234), and finger-following transitions (#177).
- Overview search with search providers (#111, #183); paged app grid with folders, drag editing, reordering and page turning (#119, #148, #165, #178, #187, #191, #244).
- Overview animation fidelity and per-frame card rendering fixes (#518, #519, #576).

### Window management
- GNOME window sizing and placement, click-to-focus, window menu, minimize, Always on Top and sticky windows (#135, #138, #141, #143).
- Alt+Tab and Super+Tab app switcher with thumbnails and switch groups (#128, #146, #157, #164, #182, #514); workspace switcher popup (#147).
- Tile preview while dragging (#151); the size-change transition for maximize, tile and fullscreen (#520).
- GNOME window-manager and shell keybindings, rebindable through their settings (#140, #145, #163, #179, #237).
- Optional niri-style scrollable tiling, compared against genuine niri frames (#197, #199, #249).

### Panel, quick settings and notifications
- Top bar, quick settings, date menu and notifications matched to GNOME 51's measured pixels (#123, #124, #156).
- Wi-Fi, wired, Bluetooth, sound output and microphone menus; NetworkManager secret agent including VPN/enterprise secrets (#159, #160, #161, #162, #180, #181, #245); battery status (#229).
- Per-app notification groups (#198); OSDs, banners and away-aware notifications (#136).
- GNOME 51 transient-surface animations for OSDs, banners, the notification list, modals and menus (#517); workspace-switch, swipe, switcher-popup and Activities-dot animations (#515); a shared motion policy and deterministic animation clock (#523); Reduced Motion honored throughout (#370).

### Lock, session and system integration
- GNOME 51 lock screen with ext-session-lock and interactive unlock, idle fade, and lock-background support (#131, #242, #262, #264, #271).
- GDM session registration; the shell acts as the polkit agent; org.gnome.Shell accelerators, screensaver and media keys work (#110, #137, #149, #226, #235).
- Screenshots, the screenshot UI and screen recording; screen and window sharing through Mutter interfaces, PipeWire and portals with consent (#115, #116, #120, #142, #202, #252, #298, #303).
- RemoteDesktop keyboard/pointer with EIS grants (#258).
- Fractional and per-output scaling and the GNOME Displays panel (#113, #114, #117, #230, #283).
- XWayland started on demand (#267, #276, #281).
- IBus input methods with the candidate window drawn by the shell, and touchpad gestures (#112, #195, #200, #204, #241).
- GNOME 51 Wayland protocols (presentation, fifo, shortcuts inhibit, dialogs and more) (#201, #205).
- GNOME Settings coverage: settings map, live fonts, hot corners, handedness, calendar week preferences, background placement and over-amplification (#253, #379, #381, #440, #445, #447).

### Performance
- DRM frame pacing, buffer-age damage, unchanged-frame skipping, occlusion culling and hidden-window throttling (#263, #293, #380, #388, #531).
- Paired GNOME 51 benchmark lanes and evidence (#251, #274, #398, #472), and Corral paired GNOME 51 benchmark tooling (#666).
- Shell fix: interrupted preview hover fades no longer leak widgets (#665, from #658).

### Packaging, release and CI
- User-facing rename from Roost to Tuna Desktop (#511, #536).
- Ubuntu 26.04 Debian package with installed GTK-shell qualification and a clean-image install check for root ownership and the GTK shell (#474, #510).
- SemVer prerelease tags `vX.Y.Z-beta.N` mapped to Debian `~beta.N` and Arch `betaN` versions (#664); release rollback runbook (#570).
- Marlin VM lane: bootc image in QEMU, hardware-session proof, feature tour (#196, #320); VM-lane startup record and Orca lifecycle flake fixes (#544, #571, #613).
- Nightly publication of the v1 victory signal (#565); fuzzing, stress and adversarial-client lanes (#236, #239, #306, #307).
- Toolchain kept current, most recently nightly-2026-10-15 (#645).

Open v1 gates (`docs/v1.md`), all unchecked for this beta:
- Not every tracked capability passes (rows above).
- Known gaps remain open (`[GNOME 51 gap]` issues).
- Daily work without any GNOME fallback is not yet proven.
- Responsiveness beating GNOME 51 on identical hardware is not yet published.
- Resource use matching GNOME 51 (CPU, memory) is not yet shown. The nested stress lane still reports shell memory growth (#658).
- The shipped Marlin image flavor is not yet qualified end to end (install, boot, real-greeter login, qualification run).
- Release safety nets (recovery without data loss, proven upgrade path) are not yet proven.
- The public v1 checklist is not yet one click from the front page.

Also:
- GPU and total-power comparisons are waived for v1 (owner decision 2026-10-13). They are a follow-up.
- Paired performance numbers against GNOME 51 are pending #668.
- Visual review gaps (missing baseline banner and lock frames; journey frames that don't show the asserted state) are tracked in #672. See `docs/reviews/v1.0.0-beta.1.md`.

## Supported configurations
- TunaOS Marlin (Arch-based bootc), x86_64, via the `marlin:tuna` image.
- Ubuntu 26.04 (amd64), `.deb` package. Debian 13 is not supported yet: it needs a packaged gtk4-layer-shell >= 1.1 backport and a separately qualified artifact. Neither target has physical-hardware qualification.
